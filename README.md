# Vishnu J Pillai — Portfolio

A responsive, single-page developer portfolio.

## Run locally
From this folder:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Before deploying
1. Put your actual resume PDF at `assets/Vishnu_J_Pillai_Resume.pdf`.
2. Replace `your.email@example.com` in `index.html` with your real email.
3. Review company names, dates and project details against your latest resume.
4. Deploy the folder to GitHub Pages, Netlify, Vercel, or another static host.

## Design
Dark developer aesthetic, lime accent, responsive layout, animated reading progress, mobile navigation, skills, experience, projects, achievement and contact sections.
